# heroquest
reproduction of the boardGame heroquest : https://fr.wikipedia.org/wiki/HeroQuest_(jeu_de_soci%C3%A9t%C3%A9)

HeroQuest is board game played by turn that is DnD-like

There is optimally 5 players :
4 players are going to play different heroes :
- the elf
- the dwarf
- the wizzard
- the barbarian
and the game-master playing "Zargon" and the different monsters on the board

The game-master handles everything the heroes sees that are not them.
For more details on the rules i advise you to read the ruleBook that you may find on internet...

The objective of this project is to make a React application that simmulates a game of this kind.
A new player gives his name then joins a game giving a game name and creates a new one if none existed before 
or joins the game if it already existed (giving the game hasn't already started or full)
Then he joins a lobby chooses his character (elf, dwarf wizzard or barbarian) and waits for the game master to start the game.

For now the game isn't really playable but the main fonctionnalities are there.
My first objective is to make it playable and not to automate the game.
At some point the game-master could be optional but it's not my objective for now...

This project is also a way for me to practice coding (and allow me to have fun with a few friends)
